杰克的网站合集分享
==================

使用方法
1. 解压 ZIP 文件。
2. 双击打开 index.html，即可在浏览器中使用，无需安装服务器。
3. 网站支持简体中文、英语、俄语、西班牙语、阿拉伯语和法语；每种语言均有对应的分类名称、页面介绍、安全提示及各网站的完整说明。
4. 搜索框可按网站名称、说明或分类标签筛选。

安全与隐私说明
- 这是第三方网站导航，不托管任何下载文件，也不对外部网站作安全或合法性担保。
- 游戏下载/压缩包站点可能涉及版权问题，也可能存在恶意软件风险。请优先选择正版渠道，并使用可信安全软件扫描文件。
- VPN、代理、IP 与 DNS 检测网站的结果不能单独证明用户正在被监视；不要据此作出身份或安全结论。
- 用户提供的自建 VPN 配置地址、Key 和账号属于可能可访问服务的敏感凭据，因此没有写入公开导航页面。请勿把订阅链接、密钥或账号公开发布。
- 第三方临时邮箱、免费 VPN、代理节点及电话号码查询服务可能收集数据；不要提交密码、银行卡信息或敏感个人资料。
